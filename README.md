# MARS — A Human Story

An immersive, scroll-driven Mars mission experience built with **HTML, CSS, and JavaScript**.  
Live site: https://akashqwert1325526.github.io/Mars-journey/

## Project Description

*MARS — A Human Story* is a cinematic frontend experience that presents a Mars mission as both a technical challenge and an emotional transformation. The journey is split into six interactive acts: departure, deep-space isolation, Mars approach, landing crisis, surface operations, and identity shift.

Users do not just scroll; they influence outcomes through gameplay moments such as launch ignition, emergency stabilization, meteor defense, hotspot exploration, and survival decisions. A real-time HUD tracks oxygen, mission stage, score, and rank. Branching logic evaluates user actions and generates a personalized ending profile, making the experience replayable.

The design process focused on atmosphere first: red-dust visual language, layered overlays, glitch typography, and motion that supports narrative pacing. Interactions were introduced act-by-act to keep the experience intense but understandable. Audio is reactive and state-aware, with ambient transitions, danger cues, UI tones, and a victory sting for high-rank endings.

Technically, the project is built with native web technologies and modular JS logic for scroll orchestration, scene transitions, and stateful interactions. The result is a hackathon-ready narrative product that combines storytelling, interaction design, and frontend engineering into a memorable mission simulation.

## Tech Stack

- HTML5
- CSS3 (native animations)
- JavaScript (vanilla, Web Audio API)
